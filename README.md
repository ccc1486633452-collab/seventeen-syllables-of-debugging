# Seventeen Syllables of Debugging

A debugging haiku for the [make.fun](https://make.fun) "Seventeen Syllables of Debugging" bounty.

## The Haiku

> Cursor blinks at three
> a red dot waits on line nine
> the bug was my code

## Run

```bash
python3 main.py
```

Writes the haiku to `/output/entry.txt` (falls back to `./output/entry.txt` if `/output` is not writable).
